# SIBSAU_BOT 🤖

**SIBSAU_BOT** — это функциональный Telegram-бот и веб-панель управления для студентов Сибирского государственного университета науки и технологий (СибГУ им. М.Ф. Решетнева).

---

## 🌟 Возможности бота

- 📅 **Расписание на сегодня и завтра:** Мгновенный просмотр пар с учетом четности недели.
- ⏳ **Live-статус пары:** Отображение текущей пары, графического прогресс-бара занятия (`[██████░░░░] 60%`) и времени до следующей пары.
- 👥 **Выбор подгруппы:** Фильтрация расписания по 1-й или 2-й подгруппе (`/subgroup`).
- 📥 **Экспорт в Календарь (.ics):** Генерация файла iCalendar на весь семестр для импорта в Google, Apple и Яндекс.Календарь (`/export`).
- 🔍 **Умный поиск и Inline-режим:**
  - В боте: поиск по предметам, кабинетам и преподавателям (`/search <запрос>`).
  - В любых беседах и чатах: ввод `@имя_бота <запрос>` для мгновенной отправки расписания.
- 🔔 **Утренний дайджест:** Автоматическая отправка расписания каждое утро перед занятиями (`/notifications`).
- 👨‍🏫 **Каталог преподавателей:** Просмотр пар и графика консультаций конкретных преподавателей.
- 🎓 **Расписание сессии:** Отдельный просмотр экзаменов и зачетов.
- 🌐 **Flask Веб-панель:** Управление пользователями, ролями, 2FA, просмотр статистики и логов в реальном времени.

## 🔧 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка окружения
Скопируйте файл конфигурации:
```bash
cp .env.example .env
```
Заполните обязательные переменные в `.env`:
- `TOKEN` — токен вашего Telegram-бота от [@BotFather](https://t.me/BotFather).
- `SCHEDULE_URL` — ссылка на расписание группы (например, `https://timetable.pallada.sibsau.ru/timetable/group/13974`).
- `OWNER_ID` — ваш цифровой Telegram ID.
- `PANEL_USER` / `PANEL_PASS` — логин и пароль для веб-панели.

### 3. Запуск
Запустите бота и веб-панель:
```bash
python main.py
```
Веб-панель будет доступна по адресу: `http://localhost:19999` (или `https://` при наличии SSL-сертификатов).

## 💬 Команды бота

### 📚 Для студентов
| Команда | Описание |
| :--- | :--- |
| `/start` | Главное меню, статус текущей пары и кнопки навигации |
| `/help` | Справка по доступным командам |
| `/search <запрос>` | Поиск по расписанию, преподавателям или аудиториям |
| `/subgroup [1\|2\|all]` | Выбор вашей подгруппы для фильтрации расписания |
| `/export` | Скачать расписание на семестр в формате `.ics` для календаря |
| `/notifications` | Включить или выключить утренний дайджест расписания |
| `/plan` | Ссылка на учебный план |
| `/map` | Карта корпусов университета |

### 🛡 Для модераторов и администраторов
| Команда | Описание |
| :--- | :--- |
| `/adduser <id>` | Разрешить доступ пользователю к боту |
| `/removeuser <id>` | Заблокировать/удалить доступ пользователя |
| `/listusers` | Список авторизованных пользователей |
| `/reload` | Сбросить и обновить кэш расписания |
| `/fullreload` | Полная перезагрузка расписания и преподавателей |
| `/stats` | Статистика использования бота |
| `/showlog [n]` | Просмотр последних $n$ строк логов |
| `/mod <id>` / `/unmod <id>` | Назначение / снятие прав модератора |
| `/broadcast <текст>` | Рассылка объявления всем пользователям |

### 👑 Для владельца (Owner)
| Команда | Описание |
| :--- | :--- |
| `/adm <id>` / `/unadm <id>` | Назначение / снятие прав администратора |
| `/restart` | Перезапуск процесса бота |
