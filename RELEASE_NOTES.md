# 🚀 Release Notes — SIBSAU_BOT v2.0.0 (Release 31.08.2026)

Комплексное мажорное обновление Telegram-бота для студентов СибГУ им. М.Ф. Решетнева и веб-панели администрирования. В этом релизе проведен глубокий рефакторинг архитектуры, внедрен широкий набор студенческих и административных инструментов, реализован полный аудит информационной безопасности (ИБ) и автоматизировано развертывание на Linux-серверах.

---

## 🌟 Ключевые нововведения

### 🤖 1. Telegram-бот (Новые студенческие инструменты)

* **📝 Персональные заметки и дедлайны (`/note`, `/notes`, `/delnote`)**:
  - Студенты могут прикреплять заметки и домашние задания к предметам (например, `/note Электроника : Сдать отчет по лабе №2 к среде`).
  - При открытии расписания в дни занятий бот автоматически выводит бейдж 📝 и список актуальных заметок к паре.
  - Потокобезопасный `NotesManager` с атомарной записью на диск (`os.replace`) и валидацией объема данных.

* **◀️ ▶️ Быстрое листание дней недели**:
  - Под каждым днем расписания добавлены интерактивные кнопки навигации `[◀️ Пн] [📅 Вт] [Ср ▶️]`, позволяющие листать всю неделю подряд без возврата в главное меню.

* **🏢 Справочник корпусов и аудиторий (`/room <код>`)**:
  - Полная база всех площадок СибГУ (С3, С1, Н, А, П, ДВС, ГЛ, Л) с адресами, описаниями кафедр и прямыми ссылками на Яндекс.Карты.
  - Мгновенный поиск по номеру аудитории (например, `/room С3-504` $\rightarrow$ корпус С3, ул. Семафорная 123, 5 этаж).

* **👥 Фильтрация по подгруппе (`/subgroup 1` / `/subgroup 2` / `/subgroup all`)**:
  - Персонализированный показ расписания: фильтрация лабораторных работ только для своей подгруппы.

* **📥 Экспорт расписания в iCalendar (`/export` / `.ics`)**:
  - Генерация стандартного файла `.ics` (RFC 5545) на весь семестр с синхронизацией в Google Calendar, Apple Calendar и Яндекс.Календарь.

* **🔍 Inline-поиск (@kb24_01_bot)**:
  - Поиск расписания и преподавателей прямо из любых групповых чатов Telegram.

* **⏳ Live Прогресс-бар текущей пары**:
  - Визуальный графический индикатор прогресса занятия в реальном времени (`[██████░░░░] 60%`).

* **🛡️ Отказоустойчивость и обработка ошибок**:
  - Внедрен глобальный перехватчик исключений `global_error_handler`, предотвращающий падение бота при неожиданных сбоях.

### 🌐 2. Веб-панель управления (Flask Admin Panel)

* **📅 Визуальный интерактивный просмотр расписания (`/schedule`)**:
  - Отображение сетки занятий (1-я неделя, 2-я неделя, сессия) в веб-интерфейсе с карточками, бейджами аудиторий и кнопкой принудительного обновления кэша.

* **⚙️ Панель динамической конфигурации (`/settings_panel`)**:
  - Просмотр и безопасное изменение рабочих параметров (`SCHEDULE_URL`, `PLAN_URL`, `SEMESTER_START`, `LOG_LEVEL`) через веб-интерфейс без ручного редактирования файлов на сервере.

* **👥 Управление пользователями и личные сообщения (`/users`)**:
  - Отображение выбранной подгруппы и статуса дайджеста для каждого студента.
  - Модальное окно для отправки личных сообщений пользователям в Telegram прямо из браузера (`/users/message/<uid>`).
  - Живой клиентский поиск по ID и никнейму.

* **📜 Продвинутый журнал событий (`/logs`)**:
  - Фильтрация логов по уровням: `Все`, `ERROR`, `WARNING`, `INFO`.
  - Прямое скачивание файла `warning.log` (`/logs/download`).
  - Безопасная очистка логов (`/logs/clear`).

* **🎨 Тёмная тема (Dark Mode)**:
  - Переключатель темы (Луна / Солнце) с сохранением состояния в `localStorage` браузера.

### 🛡️ 3. Информационная безопасность (InfoSec & Hardening)

* **🔔 Оповещения владельца (`OWNER_ID`) при попытках входа**:
  - При любых попытках авторизации в веб-панели владельцу в Telegram отправляется подробное сообщение с реальным IP, хостом, временем и статусом (`✅ Успешный вход` / `❗️ Ошибка входа: invalid credentials / invalid 2FA code / rate limit exceeded`).
  - Надежное извлечение IP клиента с поддержкой прокси (`CF-Connecting-IP`, `X-Forwarded-For`, `X-Real-IP`).

* **🧱 Защитные HTTP-заголовки (Security Headers)**:
  - `X-Frame-Options: DENY` (защита от Clickjacking).
  - `X-Content-Type-Options: nosniff` (защита от MIME-sniffing).
  - `X-XSS-Protection: 1; mode=block` (браузерный XSS-фильтр).
  - `Content-Security-Policy (CSP)` (строгая политика доверенных источников).
  - `Referrer-Policy: strict-origin-when-cross-origin`.
  - `Permissions-Policy: geolocation=(), camera=(), microphone=()`.

* **🔒 Защита от подбора паролей и фиксации сессий (Brute-Force & Session Fixation)**:
  - Rate Limiting на `/login` и `/2fa` ограничен до **5 попыток в минуту** на IP.
  - Принудительная регенерация и очистка сессии при аутентификации, флаги `HttpOnly=True`, `SameSite=Strict`, `Secure=True` (при SSL).

* **🙈 Маскирование токенов в логах (Information Disclosure Prevention)**:
  - Фильтр `TelegramFilter` автоматически маскирует любые токены ботов регулярным выражением `\b\d{8,10}:[A-Za-z0-9_-]{35}\b`.

* **🧼 Защита от SSRF / CRLF / iCal Injection**:
  - Валидация URL (`http://` и `https://`) и экранирование спецсимволов по RFC 5545.

### 🐧 4. Сетевая инфраструктура и развертывание на Linux

* **🌐 Поддержка обхода блокировок через VLESS + Reality + XHTTP**:
  - Поддержка переменной `PROXY_URL` в `.env` для маршрутизации трафика Telegram Bot API через локальный туннель Xray-core / Sing-box.
  - Полноценная поддержка раздельного проксирования для отправки запросов (`request`) и долгого поллинга (`get_updates_request`).

* **🚀 Скрипт автоматического развертывания (`setup_ubuntu.sh`)**:
  - Автоматическая установка системных пакетов (`python3`, `python3-venv`, `pip`, `git`).
  - Создание виртуального окружения `venv` и установка зависимостей.
  - Генерация и запуск системного демона `systemd` (`sibsau_bot.service`) с политикой `Restart=always`.
